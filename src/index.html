            Outlook calendar

            Automatic Outlook sync needs the DayBrief desktop app, because Outlook does not let web pages opened from a file read your calendar. In this version, add meetings with the + Meeting button on the Today page.

            Paste your calendar's published ICS link. DayBrief reads it every 30 minutes. It never changes your calendar.

            How do I get this link?
            1. Open Outlook on the web (outlook.office.com) and click the gear icon for Settings.
            2. Go to Calendar, then Shared calendars.
            3. Under Publish a calendar, choose your calendar and Can view all details (or "titles and locations"), then click Publish.
            4. Copy the ICS link (not the HTML one) and paste it above.

            Google Calendar and iCloud also give you an ICS link ("Secret address in iCal format"), so those work too. Treat the link like a password: anyone who has it can see your calendar.

            Morning popup

            The greeting bar appears the first time you open this page each day. To have it open by itself when you log in:

            • Mac: System Settings, General, Login Items, click + and choose this HTML file.
            • Windows: press Win+R, type shell:startup, and put a shortcut to this HTML file in that folder.

            A web page cannot keep itself above other windows. The desktop app can.
