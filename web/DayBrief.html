                  Outlook calendar

                  Outlook does not let a web page read your calendar directly, so this version uses a small free "bridge" in your own Google account. Set it up once, then paste its address here. DayBrief reads it every 30 minutes and never changes your calendar.

                  Set up the bridge (about 5 minutes, once)
                  1. Get your Outlook ICS link. In Outlook on the web (outlook.office.com), click the gear icon, then Calendar, Shared calendars. Under Publish a calendar, choose your calendar and Can view all details, click Publish, and copy the ICS link.
                  2. Go to script.google.com and click New project.
                  3. Delete everything in the editor and paste this code. Then replace PASTE_YOUR_OUTLOOK_ICS_LINK_HERE with your ICS link (keep the quote marks) and click the save icon. 
                    const ICS_URL = 'PASTE_YOUR_OUTLOOK_ICS_LINK_HERE';
const DATA_FILE = 'DayBrief-data.json';

function doGet(e) {
  const p = (e && e.parameter) || {};
  const text = p.action === 'load' ? loadData_() : fetchIcs_();
  return reply_(text, p.callback);
}

function doPost(e) {
  const body = JSON.parse(e.postData.contents);
  if (body.action === 'save' && body.payload && body.payload.data) saveData_(body.payload);
  return ContentService.createTextOutput('ok');
}

function fetchIcs_() {
  const url = ICS_URL.trim().replace(/^webcal:\/\//i, 'https://');
  return UrlFetchApp.fetch(url, { muteHttpExceptions: true, followRedirects: true }).getContentText();
}

function file_() {
  const files = DriveApp.getFilesByName(DATA_FILE);
  return files.hasNext() ? files.next() : null;
}

function loadData_() {
  const f = file_();
  return f ? f.getBlob().getDataAsString() : '';
}

function saveData_(payload) {
  const lock = LockService.getScriptLock();
  lock.waitLock(20000);
  try {
    const old = loadData_();
    if (old) {
      const prev = JSON.parse(old);
      if ((prev.savedAt || 0) > (payload.savedAt || 0)) return; // keep the newer copy
    }
    const text = JSON.stringify(payload);
    const f = file_();
    if (f) f.setContent(text); else DriveApp.createFile(DATA_FILE, text, 'application/json');
  } finally {
    lock.releaseLock();
  }
}

function reply_(text, cb) {
  if (cb && /^[A-Za-z_$][\w$]*$/.test(cb)) {
    return ContentService.createTextOutput(cb + '(' + JSON.stringify(text) + ');')
      .setMimeType(ContentService.MimeType.JAVASCRIPT);
  }
  return ContentService.createTextOutput(text).setMimeType(ContentService.MimeType.TEXT);
}

                  Sync across computers

                  Keep your tasks, dates and notes in your own Google Drive (one file named DayBrief-data.json), so every computer where you open DayBrief shows the same thing. It uses the same bridge as the Outlook calendar.

                  Turn on sync (once, about 3 minutes)
                  1. In Apps Script, open your bridge project. Copy the first line (the one with your ICS link) somewhere safe.
                  2. Replace all the code with the newest code from Outlook calendar > Set up the bridge (use Copy code), then put your first line back and click the save icon.
                  3. At the top of the editor, choose the function authorize and click Run. Allow access to Google Drive when asked (Advanced, then Go to your project).
                  4. Click Deploy, Manage deployments, the pencil icon, Version: New version, then Deploy. The bridge address stays the same.
                  5. Tick the box above on this computer. On your other computer, open DayBrief, connect the same bridge address, and tick the box there too.

                  Changes are saved a few seconds after you make them and checked every few minutes and whenever you come back to the tab. If two computers change things at the same moment, the newest save wins.

                  Backup

                  Your data stays on this computer. Export a backup file to move it to another computer.
